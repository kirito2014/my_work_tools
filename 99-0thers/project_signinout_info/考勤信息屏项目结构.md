### 考勤信息屏项目结构

```
考勤信息屏/
├── app.py                  # Flask应用主文件
├── static/
│   ├── css/
│   │   └── style.css       # 蓝色系主题样式
│   └── js/
│       └── script.js       # ECharts图表配置与交互
└── templates/
    └── index.html          # 主页HTML模板
```

#### 文件说明：
1. **app.py**：
   - Flask路由定义
   - 模拟考勤数据生成
   - JSON接口提供

2. **templates/index.html**：
   - 页面结构（信息卡片、图表容器）
   - Font Awesome图标引入
   - ECharts初始化

3. **static/css/style.css**：
   - 蓝色系主题配色
   - 响应式布局样式
   - 卡片与图表样式

4. **static/js/script.js**：
   - ECharts图表配置
   - 时间筛选按钮交互
   - 数据动态更新逻辑
