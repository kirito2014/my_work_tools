# 长亮科技简历生成器使用文档

## 简介

长亮科技简历生成器是一款专为企业内部使用的简历管理与生成工具，旨在简化技术人员简历的解析、管理和定制化生成过程。该工具支持从Excel文件中解析技术人员信息，从Word文档中提取简历内容，并根据不同银行客户的要求生成符合其格式规范的简历文档。

### 主要功能

- 解析技术人员Excel信息表
- 从Word文档中提取简历内容并入库
- 支持批量转换.doc文件为.docx格式
- 根据不同银行模板生成定制化简历
- 提供简历校验功能
- 支持特殊更新和银行管理功能

## 系统要求

- Windows操作系统
- Python 3.6+
- 依赖库：tkinter, ttkthemes, PIL (Pillow), openpyxl等
- Microsoft Word（用于文档转换）

## 安装说明

1. 确保已安装Python 3.6或更高版本
2. 安装所需依赖库：
   ```
   pip install pillow ttkthemes openpyxl python-docx
   ```
3. 下载或克隆项目代码到本地
4. 直接运行`resume_gui.py`启动应用程序

## 主界面功能说明

主界面分为四个主要功能区域：

1. **解析技术人员信息**：用于导入和解析Excel格式的技术人员信息表
2. **解析简历文件入库**：用于选择简历文件并提取信息存入系统
3. **简历生成**：提供多种方式生成定制化简历
4. **进度和日志显示**：显示操作进度和系统日志

## 菜单栏功能

应用程序提供了以下菜单栏功能：

- **文件菜单**：包含预处理和退出功能
- **特殊更新**：用于批量更新简历信息或人员信息
- **银行管理**：管理支持的银行模板和配置
- **简历校验**：验证生成的简历是否符合规范

## 详细操作指南

### 1. 技术人员信息解析

1. 点击「选择Excel文件」按钮，选择包含技术人员信息的Excel文件
2. 点击「解析信息」按钮开始解析
3. 解析完成后，系统会加载人员信息到数据库中

### 2. 简历文件解析入库

1. 点击「选择文件路径」按钮，选择简历Word文档
2. 点击「开始解析」按钮
3. 系统会提取简历信息并与人员信息匹配后入库

### 3. 预处理功能

预处理功能主要用于将旧版.doc格式的简历文件转换为.docx格式：

1. 从菜单栏选择「文件」→「预处理」
2. 在弹出的对话框中选择包含.doc文件的文件夹
3. 点击「开始处理」按钮
4. 系统会批量转换所有.doc文件并自动删除原文件

### 4. 简历生成

系统提供两种简历生成方式：

#### 4.1 按名单生成简历

1. 选择「按名单生成简历」选项
2. 点击「选择名单文件」按钮，选择包含员工编号的名单文件
3. 点击「确认选择」按钮
4. 在银行下拉框中选择目标银行
5. 点击「生成简历」按钮开始生成

#### 4.2 自定义生成简历

1. 选择「自定义生成简历」选项
2. 点击「更新人员名单」按钮加载所有人员信息
3. 可以使用搜索框或部门筛选功能查找特定人员
4. 在人员列表中勾选需要生成简历的人员
5. 点击「确认选择」按钮
6. 在银行下拉框中选择目标银行
7. 点击「生成简历」按钮开始生成

### 5. 特殊更新功能

特殊更新功能用于批量更新已有的简历信息：

1. 从菜单栏选择「特殊更新」→「特殊更新」
2. 选择简历文件夹和人员信息文件
3. 输入要更新的人员编号（多个用逗号分隔，全部更新输入ALL）
4. 选择更新方式（只更新简历信息、只更新人员信息或更新全部信息）
5. 点击「执行更新」按钮

### 6. 银行管理功能

银行管理功能用于管理系统支持的银行模板：

1. 从菜单栏选择「银行管理」→「银行管理」
2. 在弹出的对话框中可以添加、编辑或删除银行模板配置

### 7. 简历校验功能

简历校验功能用于验证生成的简历是否符合规范：

1. 从菜单栏选择「简历校验」→「简历校验」
2. 在弹出的对话框中选择要校验的简历文件夹或文件
3. 点击「开始校验」按钮
4. 查看校验结果和错误信息

## 使用示例

### 示例1：批量生成简历

1. 准备好包含员工编号的名单文件（如list.txt）
2. 在主界面选择「按名单生成简历」
3. 选择名单文件并确认
4. 选择目标银行（如「交通银行」）
5. 点击「生成简历」按钮
6. 等待生成完成，在output目录下查看生成的简历

### 示例2：转换旧版简历文件

1. 将所有旧版.doc格式简历放在同一文件夹中
2. 从菜单栏选择「文件」→「预处理」
3. 选择该文件夹并点击「开始处理」
4. 系统会自动将所有.doc文件转换为.docx格式并删除原文件

## 常见问题解答

### Q: 为什么无法加载人员信息？
A: 请检查Excel文件格式是否正确，确保包含必要的字段（如员工编号、姓名等）。

### Q: 简历生成失败怎么办？
A: 检查日志显示区域的错误信息，常见原因包括：模板文件不存在、人员信息不完整或格式错误。

### Q: 如何添加新的银行模板？
A: 首先准备好新银行的简历模板文件，然后通过银行管理功能添加新的银行配置。

### Q: 预处理功能可以保留原文件吗？
A: 目前预处理功能会自动删除原.doc文件，如果需要保留，请在预处理前手动备份。

## 注意事项

1. 请确保Microsoft Word已正确安装，否则文档转换功能可能无法正常工作
2. 处理大量文件时可能需要较长时间，请耐心等待
3. 生成的简历默认保存在output目录下，按银行名称分类存储
4. 定期备份项目文件夹，特别是output目录中的生成文件
